## About the project

<!-- DRAFT: this project has no written description in the portfolio; edit freely -->
Responding to Taiwan's ageing population, the project combines a healthcare center, a senior club, a sunken pool with a lazy river, and an amusement park in Kai-Yuan Park, Tainan. The towers are generated from a Voronoi pattern and built up as a waffle structure.
